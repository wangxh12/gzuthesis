# GZUThesis v0.3.0-dev：参考文献模块改造说明

基准：用户最近提供的 GZUThesis v0.2.0-dev `.dtx` 文本。主交付是 `gzuthesis.dtx`，**不要直接编辑提取出的 `.cls`**。

## 技术边界

- 不支持本科生专用参考文献分支。
- 两种后端互斥：BibTeX 使用 `gbt7714`（其内部集成 natbib）、附录独立参考文献使用自动加载的 `bibunits`；BibLaTeX 使用 Biber、`refsection`。
- 不新增中英文条目的校内差异化样式，文献著录由上游 GB/T 7714 样式包负责。
- 学校字体要求：参考文献标题小四号黑体（12 bp），条目小五号宋体（9 bp）；行高和条目距离是模板可调默认值。
- 参考文献页码默认继承正文/后置部分，**不会重置为 1**。
- BibTeX 和 BibLaTeX 作者表默认尝试列全；GB/T 7714 2025 BibTeX 依赖已安装支持 `\gbtsetup` 的新版 `gbt7714`。旧版无法自动强制列全。

## 1. 提取与替换

将 `gzuthesis.dtx` 替换到项目根目录（先确认当前本地修改没有超出此前上传的源码），然后运行：

```bash
xetex gzuthesis.ins
```

## 2. BibTeX + gbt7714 — 顺序编码制

在 `gzusetup.tex` 中采用：

```latex
\usepackage[sort]{gbt7714}
\gbtsetup{maxbibnames=0,minbibnames=0,inline=true}
\bibliographystyle{gbt7714-2025-numeric}
\gzusetup{
  cite-style = auto,
  bib-bst = {gbt7714-2025-numeric},
}
```

正文调用 `\bibliography{ref/refs}`。`gbt7714` 会加载 natbib，模板会自动加载 `bibunits`。**不要额外加载 biblatex**。

著者—出版年制则将 `\bibliographystyle` 和 `bib-bst` 同时改为 `gbt7714-2025-authoryear`，并使用著者—出版年引用命令。

## 3. BibLaTeX + Biber — 顺序编码制

```latex
\usepackage[
  backend=biber,
  style=gb7714-2025,
  sorting=none,
  defernumbers=true,
  maxbibnames=999
]{biblatex}
\addbibresource{ref/refs.bib}
\gzusetup{cite-style=auto}
```

正文调用 `\printbibliography`，**不要同时加载 natbib / gbt7714 或再调用 `\bibliography`**。
著者—出版年制选 `style=gb7714-2025ay`，通常使用 `sorting=nyt`。这两个 `.bbx` 样式依赖较新的 `biblatex-gb7714-2015` 包（包名虽然包含 2015）。

## 4. 统一排版配置（两种后端共用）

```latex
\gzusetup{
  bib-title = {参考文献},
  bib-appendix-title = {参考文献},
  bib-font = {\songti},
  bib-font-size = {9bp},
  bib-line-height = {14bp},
  bib-title-format = {\centering\heiti\fontsize{12bp}{18bp}\selectfont},
  bib-item-sep = {3bp plus 2bp minus 1bp},
  bib-hang = {21bp},
  bib-label-width = {1cm},
  bib-label-sep = {0.5em},
  bib-heading = chapter,
  bib-appendix-heading = section,
  bib-page-style = plain,
  bib-appendix-prefix = true,
}
```

`bib-heading`: chapter/section/none。`bib-appendix-heading`: section/chapter/none。`bib-page-style`: plain/empty，用于文献标题所在页；不改变正文的全局页码。`bib-label-width` 直接作用于 natbib；BibLaTeX 编号列宽仍由国标样式控制。`bib-label-sep` 控制 BibLaTeX 的标签间距。

## 5. 附录独立参考文献（两种后端写法相同）

```latex
\appendix
\chapter{补充实验}
\begin{gzuappendixrefs}
  附录文献引用\cite{example-key}。
  \gzuprintappendixbibliography{ref/refs}
\end{gzuappendixrefs}
```

正文的 `\bibliography` 或 `\printbibliography` 应放在 `\appendix` 之前。每个需要独立参考文献的附录章可使用一个 `gzuappendixrefs` 环境。该环境**必须放在对应 `\chapter` 之后**。它是显式选择，不会未经用户同意将全部附录拆分。

BibTeX 附录辅助文件会命名为 `gzuthesis-example-appendix-A.aux`、`...-B.aux` 等；每一个都需要单独执行 BibTeX。`bib-bst` 决定其著录样式，必须与正文 `\bibliographystyle` 保持一致。BibLaTeX 附录则由 Biber 对独立 `refsection` 自动处理。`bib-appendix-prefix=true` 在顺序编码制下输出 `[A.1]`、`[B.1]` 等编号。

## 6. 构建检查

```bash
# 检查发行版的国标样式版本
kpsewhich gbt7714-2025-numeric.bst
kpsewhich gbt7714-2025-authoryear.bst
kpsewhich gb7714-2025.bbx
kpsewhich gb7714-2025ay.bbx

# 先提取文档类
xetex gzuthesis.ins

# 日常多轮构建
latexmk -xelatex -gg gzuthesis-example.tex
```

BibTeX 如果没有自动生成附录 `.bbl`，需要在首轮 XeLaTeX 生成相应 `.aux` 后另行运行，例如：

```bash
bibtex build/thesis/gzuthesis-example-appendix-A
bibtex build/thesis/gzuthesis-example-appendix-B
latexmk -xelatex gzuthesis-example.tex
```

如果 `.aux` 位于其他目录，需调整上述路径。不要在生成附录 `.bbl` 后立即使用 `-gg`，以免清理这些产物。Biber 模式不运行 BibTeX。

## 7. 已验证与未验证

已在当前工作环境（TeX Live 2025/dev/Debian）使用旧版上游样式 `gbt7714-numerical/author-year` 和 `gb7714-2015/2015ay` 检验四种组合（两个后端 × 两种引用体系），每组各有正文及 A/B 两份独立附录文献，均通过 XeLaTeX + 对应后端 + 两轮 XeLaTeX，并检查了 A/B 编号和 PDF 文字。

未能在你的 WSL TeX Live 2026 与新国标 2025 版 `.bst` / `.bbx` 上执行完整验收，因此不能把上面的兼容性测试等同于 2025 国标格式验收。测试中由于当前环境缺少 TeX Gyre 正文字体，仅在**测试副本**替换为 Latin Modern；交付 `.dtx` 保持原来的字体配置。

另外，上传的原始 `.dtx` 是从 Markdown 复制的文本，包含若干被转义的 `\~`，本版将相关用法恢复为正常的 `~` 不换行空格（包括附录编号、图表清单、英文关键词分隔符）。
